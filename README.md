# Disaster Tweet Classification

Machine Learning project for classifying disaster-related tweets using text classification techniques and imbalance handling methods.

## Features

* Text preprocessing and cleaning
* TF-IDF vectorization
* Logistic Regression
* Random Forest
* Neural Network
* Class Weighting
* Random Oversampling
* SMOTE
* Performance evaluation using multiple metrics

## Project Structure

```text
disaster-tweet-classification/
│
├── data/
├── notebooks/
├── reports/
├── requirements.txt
└── README.md
```

## Dataset

Download the Disaster Tweets dataset from Kaggle and place `tweets.csv` inside the `data/` directory.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Open and run:

```text
notebooks/disaster_tweet_classification.ipynb
```

using Jupyter Notebook.
